Movie Recommendation System. 
Description: a content-based recommender built with Python, Pandas, Scikit-learn, NLTK, Streamlit. 
Features: recommends five similar movies, uses cosine similarity, includes a simple Streamlit web interface. 
Technologies used: Python, Pandas, NumPy, Scikit-learn, NLTK, Streamlit. Project files: app.py, movies.pkl, notebook. 
Note: large files like the full dataset or similarity matrix are not included here due to file size limits. 
How to run: install requirements, then streamlit run app dot py.
